This project contains JUnit 5 test cases for the following classes:
- Calculator
- Product
- UserService
- RecipeBook

 Implemented Features
- Unit testing for all methods (valid & invalid inputs)
- @DisplayName for readable tests
- Parameterized tests
- Timeout tests
- Multiple assertions (assertEquals, assertThrows)
- Test Suite using @Suite
- Ordered tests (CalculatorTest)
- Lifecycle hooks (@BeforeAll, @AfterAll, @BeforeEach, @AfterEach)
- Disabled failing test
- Parallel execution (@Execution)
